ЛАНДШАФТ ПАРК — ЗИМНИЙ ХИРО

Распакуйте содержимое архива в корень проекта с заменой файлов.
Установка зависимостей и миграции не нужны. Затем перезапустите приложение обычным способом и обновите страницу Ctrl+F5.

Летний оригинал site/images/hero-bgr.webp НЕ изменён и НЕ удалён.
Зимний вариант: site/images/hero-winter.webp.

Снег рисуется локально, не загружает видео и не требует сторонних сервисов.
Запускается после загрузки страницы при хорошем соединении по данным браузера.
При недоступности Network Information используются реальные сетевые тайминги загрузки зимней картинки и страницы; если данных недостаточно, анимация выключена.
Стабильность соединения нельзя гарантированно определить в браузере: используется осторожная оценка.
При экономии трафика, слабой сети, офлайн, уменьшении движения, скрытии вкладки или уходе с хиро снег выключается.

КАК ВЕРНУТЬ ЛЕТО
1. В public/index.html, site/styles/main.scss, site/css/main.css и site/css/main.min.css замените hero-winter.webp на hero-bgr.webp.
2. В public/index.html удалите подключение hero-snow.js.
3. Измените версию CSS в public/index.html (например, v=summer-2027), чтобы обновился кеш.

Перед Git-командами на компьютере отца проверьте git status, git remote -v и git branch -vv.
